runtime/apptainer replaces the SPANK plugin slurm-singularity-exec on clusters with Slurm 26.11 or later. This page lists the differences.

For users

SPANK pluginruntime/apptainer
--singularity-container=IMAGE--container=IMAGE
--singularity-container= (empty, no container)--container=none
--singularity-bind=SPEC--apptainer-bind=SPEC
--singularity-args=ARGS--apptainer-args=ARGS
--singularity-no-bind-defaults--apptainer-no-default-binds
SLURM_SINGULARITY_CONTAINERSRUN_CONTAINER, SBATCH_CONTAINER, SALLOC_CONTAINER
SLURM_SINGULARITY_BINDSRUN_APPTAINER_BIND, ...
SLURM_SINGULARITY_ARGSSRUN_APPTAINER_ARGS, ...
SLURM_SINGULARITY_GLOBALNot available for users. See GlobalArgs.
SLURM_SINGULARITY_DEBUG=trueNot available. The log of slurmd shows the command line at debug level.

The plugin does not read the SLURM_SINGULARITY_* variables. Change them in job scripts and module files.

Changes of behaviour

  • The task launch is complete. A task in a container now has the limits of the submit shell and the results of the TaskProlog and of --task-prolog. See Task launch.
  • No message before the task. The SPANK wrapper printed Start container image ... to the output of each task. The plugin prints nothing.
  • The image is in the job record. scontrol show job and the accounting show the image in the Container field.
  • The steps of a job use the options of the job, and srun --container=none switches the container off for one step. See Steps of a job.
  • MPI needs no bind path. The plugin binds the files of the PMIx server of the step into the container. The default bind of the SPANK plugin had the spool directory of slurmd for this. See MPI.
  • No shell between Slurm and Apptainer. The plugin starts Apptainer directly. Values with spaces and quotes arrive without change.

Steps of the migration

  1. Update the cluster to Slurm 26.11 or later.
  2. Build and install the plugin for that Slurm release.
  3. Write apptainer.conf from the arguments of the SPANK plugin in plugstack.conf. The table above shows the keys.
  4. If the wrapper script of the site has changes, move them into a wrapper for Executable. The new wrapper gets the complete command line of Apptainer as its arguments.
  5. Set DefRuntimePlugin=runtime/apptainer in slurm.conf.
  6. Remove the SPANK plugin from plugstack.conf. Do not use the two plugins for one job.
  7. Tell the users the new option names.
