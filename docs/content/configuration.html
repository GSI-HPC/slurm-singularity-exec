apptainer.conf sets the defaults of the site. The file is optional. Without it, the plugin runs apptainer exec IMAGE COMMAND with the options of the user only.

Location and format

slurmstepd reads the file on each compute node when a step starts, from the directory of slurm.conf. A change applies to the next step. It is not necessary to restart a daemon.

The file has the syntax of slurm.conf: one Key=Value in each line, keys in any case, comments after #. Put a value with a space in double quotes.

Bind=/etc/slurm,/run/munge,/var/spool/slurmd,/lustre,/cvmfs
ExecArgs="--no-mount tmp --env 'SITE=GSI Darmstadt'"
AllowUserArgs=yes

A key that the plugin does not know stops each step. The plugin does not start a task with a configuration that it cannot read completely. The log of slurmd shows the line that has the error.

A node in configless mode gets only the files that slurmctld sends. Install apptainer.conf on such a node in the directory of the default slurm.conf, usually /etc/slurm.

Executable

The program that the plugin runs in place of apptainer. The plugin searches a name without a directory in the PATH of the job, then in /usr/local/bin:/usr/bin:/bin.

  • SingularityCE has the same command line. Set Executable=singularity.
  • A wrapper of the site can prepare the environment and then start Apptainer. The plugin gives it the complete command line.
#!/bin/sh
# Add the tools of the site to the PATH in each container.
export APPTAINERENV_PREPEND_PATH=/opt/site/bin
exec /usr/bin/apptainer "$@"
Executable=/usr/local/libexec/apptainer-site

DefaultImage

The image for steps that do not name one. With this key, each task of the cluster runs in a container, unless the user selects --container=none.

DefaultImage=/images/site-default.sif

Bind

Bind paths for each container, with commas between them, in the format of apptainer exec --bind. Users add paths with --apptainer-bind and leave out these paths with --apptainer-no-default-binds.

Bind=/lustre,/cvmfs,/data/run7:/input:ro

To let batch scripts and tasks in a container use srun, bind the Slurm configuration, the socket of munge and the spool directory of slurmd. The image must have the Slurm commands of the same release.

Bind=/etc/slurm,/run/munge,/var/spool/slurmd

GlobalArgs

Arguments for apptainer itself, before exec.

GlobalArgs=--silent

ExecArgs

Arguments for apptainer exec. They come before the bind paths and before the arguments of the user. The plugin splits the value into words like a shell does: single quotes keep a space in one argument.

ExecArgs="--nv --env 'SITE=GSI Darmstadt'"

AllowUserArgs

AllowUserArgs=no refuses --apptainer-args and its variables. A step with user arguments then fails with --apptainer-args is not permitted on this cluster.

This key keeps the command line of all jobs uniform. It is not a security boundary: the plugin starts Apptainer as the user, and a user can also start Apptainer in a job without the plugin.
