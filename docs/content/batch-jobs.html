With --container, sbatch runs the batch script in the container. The steps of the job use the same image.

The batch script

Set the options on the command line or in #SBATCH lines.

#!/bin/bash
#SBATCH --container=/images/alma9.sif
#SBATCH --apptainer-bind=/lustre

cd /lustre/alice/run7
./solver input.dat

Slurm stores the script in the spool directory of the compute node, which the image does not contain. The plugin binds the script into the container, read-only.

The interpreter of the script, /bin/bash in the example, is a program of the image. An image without that interpreter cannot run the script.

srun in the batch script

A batch script in a container can only use the programs of the container. To start steps, it needs srun. There are two ways to get it.

Keep the script on the host

Do not give --container to sbatch. Set the image for the steps in the script. This works with each image.

#!/bin/bash
#SBATCH --ntasks=8

export SRUN_CONTAINER=/images/alma9.sif     # image of all steps
srun ./solver input.dat                     # 8 tasks, each in the container
srun --container=none hostname              # this step is on the host

Put Slurm in the container

The script can run in the container if the container has the Slurm commands of the cluster and can reach the Slurm daemons. This is a task for the administrator of the cluster and the author of the image:

  • The image has the Slurm commands, of the same release as the cluster.
  • Bind in apptainer.conf adds the Slurm configuration, the socket of munge and the spool directory of slurmd to each container.
#!/bin/bash
#SBATCH --container=/images/alma9-slurm.sif
#SBATCH --ntasks=8

srun ./solver input.dat     # the steps use the image of the job

--wrap

$ sbatch --container=/images/alma9.sif --wrap 'cat /etc/redhat-release'

salloc

salloc accepts the same options. The command that salloc starts runs on the submit host. The steps that it starts with srun run in the container.

$ salloc --container=/images/alma9.sif -n4
salloc: Granted job allocation 4713
$ srun cat /etc/redhat-release
AlmaLinux release 9.6 (Sage Margay)

On a cluster with LaunchParameters=use_interactive_step, salloc starts a shell on a compute node as a step. That shell is then in the container.
