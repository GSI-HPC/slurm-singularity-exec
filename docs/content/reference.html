All options, variables and configuration keys of runtime/apptainer on one page.

Options

srun, sbatch and salloc have these options when the plugin is the runtime of the command.

OptionFunction
--container=IMAGERun the tasks in this image. IMAGE is a path or a URI that apptainer exec accepts. none or an empty value selects no container.
--apptainer-bind=SPEC[,SPEC...]Add bind paths. SPEC is SRC[:DEST[:OPTS]], as for apptainer exec --bind. An empty value removes the bind paths of the job from a step.
--apptainer-args=ARGSAdd arguments to apptainer exec. The plugin splits ARGS into words with the quoting rules of a shell. The site can refuse this option.
--apptainer-no-default-bindsLeave out the bind paths of Bind in apptainer.conf.

Slurm has these options to select the runtime:

OptionFunction
--runtime=apptainerUse this plugin for the command. Put it before the other options. See Select the runtime.
--runtime=noneUse no runtime plugin.
--runtime=listPrint the runtime plugins of the cluster.

Variables in a job

The plugin sets these variables in the environment of the job. srun in the job uses them as defaults for its steps.

VariableValue
SLURM_CONTAINERThe image of the job.
SLURM_APPTAINER_BINDThe bind paths of the job.
SLURM_APPTAINER_ARGSThe Apptainer arguments of the job.
SLURM_APPTAINER_NO_DEFAULT_BINDS1 if the job leaves out the bind paths of the site.
SRUN_RUNTIMEapptainer, if the job selected the plugin and it is not the default runtime.

apptainer.conf

The file is in the directory of slurm.conf. It has the syntax of slurm.conf. All keys are optional, and the file itself is optional. See Configuration.

KeyDefaultFunction
ExecutableapptainerThe program that the plugin starts. A name without a directory is searched in the PATH of the job, then in the system directories.
DefaultImagenoneThe image of steps that name none.
BindnoneBind paths for each container, comma-separated.
GlobalArgsnoneArguments for apptainer, before exec.
ExecArgsnoneArguments for apptainer exec, before those of the user.
AllowUserArgsyesno refuses --apptainer-args.

slurm.conf

ParameterFunction
DefRuntimePlugin=runtime/apptainerMake the plugin the runtime of all commands. Recommended.

The command line

For each task of a step with an image, the plugin starts this command, with the environment of the job:

Executable [GlobalArgs] exec [ExecArgs]
    [--bind SPEC]...    # Bind, unless --apptainer-no-default-binds
    [--bind SCRIPT:SCRIPT:ro]    # the batch script, for the batch step
    [--bind STEPDIR]    # the directory of the step, if it has files (PMIx)
    [--bind SPEC]...    # --apptainer-bind
    [ARGS]              # --apptainer-args
    IMAGE COMMAND [ARGUMENT]...

SlurmdDebug=debug writes the command line of each task to the log of slurmd.
